Python Sandbox Mockup

Python sandbox for TurboLLM chat

A clickable design proposal for issue #52 ("small contained Linux environment and file generation"). Nothing here is built yet. Pick a scenario, then click through it, or use the buttons inside the chat as you would in the app.

ReuseExtendNewv2

Timings and limits come from a spike: Pyodide 0.29.5 inside Deno 2.9.6 with no network permission, run on an i5-1135G7 laptop (16 GB, about 3 GB free) and in CI on Ubuntu, macOS and Windows (github.com/shunya0/turbollm-52-sandbox-spike). File references point at TurboLLM main at 632fae6c. Proposal by @shunya0.
